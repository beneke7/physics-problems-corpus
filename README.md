# Physics problem corpus

Public, searchable metadata index for the physics-problem corpus.

Open the [catalogue](https://beneke7.github.io/physics-problems-corpus/) or download [`catalog.json`](catalog.json).

The public finder publishes metadata and outbound links only. A separate
`/internal/` Pages view contains a convenience copy of the corpus Markdown for
collaborators; its shared-key screen is not security, since GitHub Pages files
remain publicly downloadable by direct URL. Raw source PDFs and the large
figure tree are intentionally excluded. The linked sources retain their own
copyright and reuse terms.

Idea IDs remain stable in `catalog.json`; `idea_labels` provides compact display names for the finder. Eötvös language metadata is intentionally HU-only because its translations are private.
