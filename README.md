# Physics problem corpus

Public, searchable metadata index for the physics-problem corpus.

Open the [catalogue](https://beneke7.github.io/physics-problems-corpus/) or download [`catalog.json`](catalog.json).

This repository publishes metadata and outbound links only: problem statements, solutions, translations, scans, figures, and local archive paths are intentionally excluded. The linked sources retain their own copyright and reuse terms.

Idea IDs remain stable in `catalog.json`; `idea_labels` provides compact display names for the finder. Eötvös language metadata is intentionally HU-only because its translations are private.
