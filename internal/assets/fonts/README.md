# Latin Modern Roman web fonts

The internal viewer and print export use four full-coverage OpenType Latin Modern Roman fonts (regular, bold, italic, and bold italic) from TeX Live. They include Hungarian double-acute letters (`ő`, `ű`), which the older Latin-1 WOFF subset does not. The WOFF files are retained for compatibility. Latin Modern is based on Donald Knuth's Computer Modern; the original Latin Modern fonts are by Bogusław Jackowski and Janusz M. Nowacki.

The files have been renamed for this project. They are distributed under the GUST Font License (LPPL 1.3c or later); see `GUST-FONT-LICENSE.txt` and `MANIFEST.txt`.
