# Latin Modern Roman web fonts

These four WOFF files are Latin Modern Roman regular, bold, italic, and bold italic, sourced from the `lalten/lmweb` web-font repackaging. Latin Modern is based on Donald Knuth's Computer Modern; the original Latin Modern fonts are by Bogusław Jackowski and Janusz M. Nowacki.

The files have been renamed for this project. They are distributed under the GUST Font License (LPPL 1.3c or later); see `GUST-FONT-LICENSE.txt` and `MANIFEST.txt`.

Upstream: `lalten/lmweb`, `font/` and `style/latinmodern-roman.css`.
