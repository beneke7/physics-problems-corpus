If there is more than one stable solution then the question of which solution is actually realized is resolved based on the history (e.g. if the voltage applied to the circuit has been increased or decreased) because internally, nonlinear elements obey inertia (for instance, the density of charge carriers can change fast, but not instantaneously) and it will not jump from one equilibrium state to another without a good reason (such as a loss of stability or disappearance of the current solution branch).
