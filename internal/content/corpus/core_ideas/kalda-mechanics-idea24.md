If the system changes at high frequency, then it is often pratical to use time-averaged values $\langle X\rangle$ instead of detailed calculations. In more complicated situations a highfrequency component $\tilde{X}$ might have to be included (so that $X=\langle X\rangle+\tilde{X})$.
