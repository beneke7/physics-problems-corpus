If the impedance of a circuit is dominated by inductors and capacitors ${ }^{35}$ the number of its natural oscillation modes can be found as follows. Find the number of linearly independent loops $N_{l}$ for the given circuit (cf. idea 13); find the number of such linearly independent loops $N_{=}$which contain only one type of elements (all resistors, all inductors, or all capacitors); the number of natural modes is then given by $N_{m}=N_{i}-N_{=}$. In addition to that, each linearly independent loop containing only inductors contributes one zero-frequency mode: a constant current can circulate in each such a loop.
