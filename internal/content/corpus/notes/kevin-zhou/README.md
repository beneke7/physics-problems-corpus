# Kevin Zhou Olympiad handouts

This bundle covers the non-solution Physics Olympiad handouts published on
[knzhou.github.io](https://knzhou.github.io/). The linked solution PDFs are
kept as provenance sources but are not duplicated as solution records in this
pass. Explanatory notes, examples, remarks, and numbered problem statements
are translated and audited separately.

The exact source list, pinned snapshot, and licensing caution are recorded in
[sources/kevin_zhou/README.md](../../../sources/kevin_zhou/README.md). Novel
problem candidates are accepted only through the overlap report.

The completed archival and consistency result is recorded in the
[Kevin Zhou final audit](../../../reports/kevin-zhou-final-audit.md), with the
handout-note details in the
[structure audit](../../../reports/kevin-zhou-notes-structure-audit.md).

The 103 explicitly marked examples from Kevin's personal `phy.pdf` notes are
stored in this same bundle as `phy-exNNN.md` reference examples, with complete
Hungarian mirrors under `corpus/notes_hu/kevin-zhou/`. The full lecture text is
retained only in `sources/kevin_zhou/text/notes/`.
