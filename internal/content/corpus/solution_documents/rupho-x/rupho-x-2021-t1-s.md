A1 1.00       При какой температуре тепловых резервуаров тепловая машина прекратит работу?


Пусть T и T — температуры горячего и холодного тел в некоторый момент времени.
           1     2


В силу идеальности тепловой машины изменение энтропии системы в любой момент будет равно нулю:
                                                                         T1                            T2
                                                        ΔS = C ln                    + C ln                    = 0         ⇒        T1 T2 = Th Tc
                                                                         Th                            Tc




Машина прекратит работу, когда температуры резервуаров сравняются (T                            end    = T1 = T2 )          .


   Ответ:

                                                                             Tend = √Th Tc ≈ 432K




 A2 1.00       Какую работу совершит тепловая машина за время своей работы?


Так как система изолирована, работу легко найти из закона сохранения энергии:

                                                            A = W0 − W = C(Th + Tc ) − C(T1 + T2 )


                                                                        Aend = C (Th + Tc − 2√Th Tc )




   Ответ:

                                                               Aend = C(√Th − √Tc )
                                                                                                                      2
                                                                                                                          ≈ 29, 9     кДж
