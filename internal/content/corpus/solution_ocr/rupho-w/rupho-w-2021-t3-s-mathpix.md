Запишем уравнения Менделеева-Клапейрона для обеих частей сосуда

$$
\begin{gathered}
p V _ { Л } = \nu R T \\
p V _ { \Pi } = \nu R T _ { 0 }
\end{gathered}
$$

Учтём неизменность объёма сосуда

$$
V _ { Л } + V _ { \Pi } = 2 V _ { 0 }
$$

Из данных соотношений вытекает следующее

$$
p = \frac { \nu R \left( T + T _ { 0 } \right) } { 2 V _ { 0 } }
$$

В начальный момент

$$
p _ { 0 } = \frac { \nu R T _ { 0 } } { V _ { 0 } }
$$

откуда

Ответ:

$$
p = \frac { p _ { 0 } } { 2 T _ { 0 } } \left( T + T _ { 0 } \right)
$$
