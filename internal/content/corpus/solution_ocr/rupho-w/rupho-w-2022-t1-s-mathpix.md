А1 ${ } ^ { 0.50 }$ Выразите заряды обкладок конденсатора $q _ { 1 } ( x )$ и $q _ { 2 } ( x )$ через $\mathcal { E } , S , d , q , x$ и физические постоянные.

Рассмотрим смещение пластины на величину $x$ от центра. Найдём разность потенциалов на обкладках 1 и 2 в поле пластины.

$$
\varphi _ { 1 q } - \varphi _ { 2 q } = - 2 E _ { q } x = - \frac { q x } { S \epsilon _ { 0 } }
$$

С другой стороны, поскольку конденсатор изначально не заряжен, разность потенциалов в поле конденсатора

$$
\varphi _ { 1 C } - \varphi _ { 2 C } = \frac { q _ { 1 } d } { S \epsilon _ { 0 } }
$$

Суммарно

$$
\varphi _ { 1 } - \varphi _ { 2 } = \mathcal { E } = \frac { q _ { 1 } d - q x } { S \epsilon _ { 0 } }
$$

откуда

$$
q _ { 1 } = - q _ { 2 } = \frac { q x } { d } + \frac { \epsilon _ { 0 } \mathcal { E } S } { d }
$$

Уравнение движения можно записать в виде

$$
\frac { m S \epsilon _ { 0 } d } { q ^ { 2 } } \frac { d ^ { 2 } x } { d t ^ { 2 } } = x + \frac { \mathcal { E } S \epsilon _ { 0 } } { q }
$$

Подставляя полученный вид зависимости $x ( t )$, сразу находим

$$
\begin{aligned}
& a = \frac { q } { \sqrt { m S \epsilon _ { 0 } d } } \\
& C = - \frac { \mathcal { E } S \epsilon _ { 0 } } { q }
\end{aligned}
$$

Далее учтём, что $x = 0 , \frac { d x } { d t }$ в момент времени $t = 0$

$$
\begin{aligned}
& x = A + B + C = 0 \\
& \frac { d x } { d t } = a ( A - B ) = 0
\end{aligned}
$$

откуда

$$
A = B = - \frac { C } { 2 }
$$

и окончательно

$$
A = B = \frac { \mathcal { E } S \epsilon _ { 0 } } { 2 q }
$$

С5 ${ } ^ { 0.50 }$ Какое количество теплоты $Q _ { R _ { 0 } }$ выделится на сопротивлении $R _ { 0 }$ ? Ответ выразите через $\mathcal { E } , C$ и $C _ { 0 }$.

В начальный момент в цепи выделяется количество теплоты

$$
Q _ { 0 } = \frac { q _ { C } \mathcal { E } } { 2 } = \frac { C C _ { 0 } \mathcal { E } ^ { 2 } } { 2 \left( C + C _ { 0 } \right) }
$$

В установившемся режиме конденсатор $C _ { 0 }$ не заряжен, поэтому за всё время в цепи выделяется количество теплоты

$$
\begin{gathered}
Q _ { \infty } = \frac { C \mathcal { E } ^ { 2 } } { 2 } \\
Q _ { R _ { 0 } } = Q _ { \infty } - Q _ { 0 } = \frac { C ^ { 2 } \mathcal { E } ^ { 2 } } { 2 \left( C + C _ { 0 } \right) }
\end{gathered}
$$
