A1 ${ } ^ { 1.50 }$ Найдите сопротивления резисторов $R$.

Поскольку диоды одинаковые а конденсатор в начальный момент не заряжен, через диоды протекает одинаковые токи силой $I _ { D }$. Из второго закона Кирхгофа

$$
\begin{aligned}
& U _ { D } + 2 I _ { D } R = \mathcal { E } \\
& \left( I _ { C } - I _ { D } \right) R = \mathcal { E }
\end{aligned}
$$

Откуда

$$
R = \frac { 3 \mathcal { E } - U _ { D } } { 2 I _ { C } } = 200 \mathrm { OM }
$$

А2 ${ } ^ { 2.50 }$ Найдите ёмкость конденсатора $C$.

Начиная с момента времени $t = 18$ с. Это означает, что сила тока, протекающего через резистор и диоды, в дальнейшем остаётся постоянной.Из первого закона Кирхгофа

$$
\mathcal { E } = \frac { q _ { C } } { C } + \left( I _ { C } - I _ { 1 } \right) R
$$

откуда

$$
R \frac { d I _ { C } } { d t } + \frac { I _ { C } } { C } = 0
$$

Построим на отельном листе миллиметровой бумаги зависимость показаний амперметра от времени при значениях $t$ от 18 с до 25 с и проведём к графику касательную в некоторой точке.

$$
R C = - \frac { I _ { C } } { \frac { d I _ { C } } { d t } } = 20 \mathrm { c }
$$

откуда

$$
C = 0,1 \Phi
$$

А3 ${ } ^ { 4.00 }$ Получите зависимость силы тока в диодах от напряжения на нём в максимально широком диапазоне. В качестве ответа принимаются два столбца таблицы. Эти два столбца должны быть вами отмечены звездочкой в листе ответов.

Пусть $I _ { 1 } , I _ { 2 }$ и $U _ { 1 } , U _ { 2 }$ - силы тока и напряжения на диодах $D _ { 1 }$ и $D _ { 2 }$ соответственно. Тогда

$$
\begin{gathered}
U _ { C } + \left( I _ { C } - I _ { 1 } \right) R = \mathcal { E } \\
U _ { 2 } + \left( I _ { 1 } + I _ { 2 } \right) R = \mathcal { E } \\
U _ { C } + U _ { 1 } = U _ { 2 }
\end{gathered}
$$

Рассчитывать $I _ { 1 } , I _ { 2 }$ и $U _ { 1 }$ будем по следующим формулам

$$
\begin{aligned}
& U _ { 1 } = U _ { 2 } - U _ { C } \\
& I _ { 1 } = I _ { C } - \frac { \mathcal { E } - U _ { C } } { R } \\
& \frac { I _ { 2 } } { 2 } - I _ { 1 } = \frac { 2 \mathcal { E } - U _ { C } - U _ { 2 } } { R } - I _ { C }
\end{aligned}
$$
