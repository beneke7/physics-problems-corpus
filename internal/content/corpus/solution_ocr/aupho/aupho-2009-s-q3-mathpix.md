Question 3
What is the slope of a plot of $\frac { 1 } { f }$ versus $l$ ? Assume that the other quantities in the equation above are constant.

(A) $\frac { 2 n - 1 } { 4 } v _ { s }$
(B) $\frac { l _ { 0 } } { v _ { s } } \frac { 4 } { 2 n - 1 }$
(C) The plot will not be a straight line.
(D) $\frac { 4 } { 2 n - 1 } \frac { 1 } { v _ { s } }$
(E) $\frac { 2 n - 1 } { 4 } \left( 1 - l _ { 0 } \right) v _ { s }$

Solution: (d) -

$$
\frac { 1 } { f } = \frac { 4 } { 2 n - 1 } \frac { 1 } { v _ { s } } \left( l + l _ { 0 } \right)
$$
