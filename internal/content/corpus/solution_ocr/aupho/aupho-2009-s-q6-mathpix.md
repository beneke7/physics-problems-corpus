Question 6
Someone analysing an electric circuit obtains the equations

$$
\begin{aligned}
10 \mathrm {~V} - I _ { 1 } ( 15 \Omega ) - I _ { 3 } ( 5 \Omega ) & = 0 \\
2 \mathrm {~V} - I _ { 1 } ( 5 \Omega ) - I _ { 3 } ( 7 \Omega ) & = 0 \\
I _ { 1 } + I _ { 3 } & = I _ { 2 }
\end{aligned}
$$

Note that V is the unit volts, and $\Omega$ is the unit Ohms. How do the magnitudes of the three currents $I _ { 1 } , I _ { 2 }$ and $I _ { 3 }$ compare?

(A) $\left| I _ { 3 } \right| > \left| I _ { 1 } \right| > \left| I _ { 2 } \right|$
(B) $\left| I _ { 2 } \right| > \left| I _ { 3 } \right| > \left| I _ { 1 } \right|$
(C) $\left| I _ { 2 } \right| > \left| I _ { 1 } \right| > \left| I _ { 3 } \right|$
(D) $\left| I _ { 1 } \right| > \left| I _ { 3 } \right| > \left| I _ { 2 } \right|$
(E) $\left| I _ { 1 } \right| > \left| I _ { 2 } \right| > \left| I _ { 3 } \right|$

Solution: (e) - combining the first two equations by subtracting 5 times the second from the first gives

$$
I _ { 1 } ( 10 \Omega ) + I _ { 3 } ( 30 \Omega ) = 0
$$

so $I _ { 1 } = - 3 I _ { 3 }$. Substituting into the third equation gives $I _ { 2 } = - 2 I _ { 3 }$.
