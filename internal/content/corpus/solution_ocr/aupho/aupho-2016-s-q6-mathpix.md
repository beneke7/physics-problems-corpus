Question 6
The electrostatic force $F _ { e }$ that an object of charge $Q$ exerts on another object of charge $q$ is given by Coulomb's law:

$$
F _ { e } = \frac { 1 } { 4 \pi \varepsilon _ { 0 } } \frac { Q q } { r ^ { 2 } } ,
$$

where the charges of the two objects, $Q$ and $q$, are measured in units of coulombs (C), and $r$ is the distance separating the two objects.
What are the units of the constant $\varepsilon _ { 0 }$ ?

a. $\mathrm { kg } \cdot \mathrm { m } ^ { 3 } \cdot \mathrm {~s} ^ { - 2 } \cdot \mathrm { C } ^ { 2 }$
b. $\mathrm { kg } \cdot \mathrm { m } ^ { - 3 } \cdot \mathrm {~s} ^ { 2 } \cdot \mathrm { C } ^ { - 2 }$
c. $\mathrm { kg } . \mathrm { m } . \mathrm { s } ^ { 2 } . \mathrm { C } ^ { - 2 }$
d. $\mathrm { s } ^ { 2 } . \mathrm { C } ^ { 2 } . \mathrm { kg } ^ { - 1 } . \mathrm { m } ^ { - 3 }$
e. $\mathrm { s } ^ { 2 } . \mathrm { C } ^ { 2 } . \mathrm { kg } ^ { - 1 } . \mathrm { m } ^ { - 1 }$

Solution: d. Coulomb's Law can be rearranged to give

$$
\varepsilon _ { 0 } = \frac { 1 } { 4 \pi } \frac { Q q } { r ^ { 2 } F _ { e } } .
$$

Since the units of both sides of the equation must be equal, the S.I. unit of charge is C, the S.I. unit of distance is m and the S.I. unit of force can be written kg.m.s ${ } ^ { - 2 }$ the unit of $\varepsilon _ { 0 }$ is

$$
\frac { \mathrm { C } ^ { 2 } } { \mathrm {~m} ^ { 2 } \cdot \mathrm {~kg} \cdot \mathrm {~m} \cdot \mathrm {~s} ^ { - 2 } } ,
$$

and index laws can be used to simplify this to give the expression in response d. above.
