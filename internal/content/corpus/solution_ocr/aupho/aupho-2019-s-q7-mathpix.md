Question 7
Ali has spent too much time deciding what to do, and only takes one pair of measurements. He measures the mass of the weight to be $( 100 \pm 5 ) \mathrm { g }$ and the stretch, $s$, when he hangs it on the spring to be $( 5.0 \pm 0.5 )$ cm. Based on these data, the spring constant is:

a. $( 20.0 \pm 0.2 ) \mathrm { N } / \mathrm { m }$
b. (20±3) N/m
c. $( 20 \pm 6 ) \mathrm { N } / \mathrm { m }$
d. $( 200 \pm 20 ) \mathrm { N } / \mathrm { m }$
e. $( 200 \pm 30 ) \mathrm { N } / \mathrm { m }$

Solution: $\mathrm { b } . k = \frac { F _ { \text {applied } } } { s } = \frac { m g } { s } = \frac { 0.100 \mathrm {~kg} \times 10 \mathrm {~m} , \mathrm {~s} ^ { - 2 } } { 0.05 \mathrm {~m} } = 20.0 \mathrm {~N} / \mathrm { m }$. When multiplying or dividing numbers the relative uncertainties add. Here the relative uncertainty in $s$ is $\frac { \Delta s } { s } = \frac { 0.5 } { 5.0 } = 0.1$ and the relative uncertainty in $m$ is $\Delta m / m = 5 / 100 = 0.05$. Hence, $\Delta k / k = \Delta s / s + \Delta m / m = 0.1 + 0.05 = 0.15$, and $\Delta k = 0.15 \times 20.0 = 3 \mathrm {~N} / \mathrm { m }$.
