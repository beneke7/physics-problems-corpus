Question 4
What is the slope of a plot of $f$ versus $\frac { 1 } { l }$ ? Assume that the other quantities in the equation above are constant.

(A) $\frac { 2 n - 1 } { 4 } v _ { s }$
(B) $\frac { l _ { 0 } } { v _ { s } } \frac { 4 } { 2 n - 1 }$
(C) The plot will not be a straight line.
(D) $\frac { 4 } { 2 n - 1 } \frac { 1 } { v _ { s } }$
(E) $\frac { 2 n - 1 } { 4 } \left( 1 - l _ { 0 } \right) v _ { s }$

Solution: (c) -

$$
f = \frac { 2 n - 1 } { 4 } v _ { s } \frac { 1 } { l + l _ { 0 } } ,
$$

so $f$ doesn't depend linearly on $1 / l$.
