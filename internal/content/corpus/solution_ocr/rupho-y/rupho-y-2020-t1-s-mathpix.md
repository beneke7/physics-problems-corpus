A1 ${ } ^ { 3 - 50 }$ Найдите работу $A$ газа в цикле.

Поскольку нам известны изменения температур в каждом из политропных процессов, для нахождения работы газа в цикле и КПД цикла нам необходимо найти теплоёмкости в процессах 13 и 23. Найдём теплоёмкость газа в зависимости от показателя политропы

$$
n = \frac { C _ { P } - C } { C _ { V } - C }
$$

Выражение для теплоёмкости

$$
C = C _ { V } + \frac { R } { 1 - n }
$$

Таким образом,задача сводится к поиску показателей политроп 13 и 23. Далее можно действовать разными способами, в решении мы предложим наиболее быстрый.

1 из способов связан с энтропией.Из определения энтропии $d S = \frac { \delta Q } { T } = C d \ln \left( \frac { T } { T _ { 0 } } \right)$. Значит, в политропном процессе график $S \left( \ln \left( \frac { T } { T _ { 0 } } \right) \right)$ линеен и имеет угловой коэффициент равный $C$.

Приравнивая изменение энтропии в процессе 12 к изменению энтропии в процессах 13 и 32 , получим

$$
C _ { 13 } \ln \left( \frac { T _ { 3 } } { T _ { 1 } } \right) + C _ { 32 } \ln \left( \frac { T _ { 2 } } { T _ { 3 } } \right) = C _ { P } \ln \left( \frac { T _ { 2 } } { T _ { 1 } } \right)
$$

Учитывая соотношение $T _ { 3 } ^ { 2 } = T _ { 1 } T _ { 2 }$ из условия, получаем эквивалентное равенство

$$
C _ { 13 } + C _ { 32 } = 2 C _ { P }
$$

Принимая во внимание зависимость $C ( n )$, получаем второе уравнение для определения показателей политропы

$$
\frac { 1 } { 1 - n _ { 13 } } + \frac { 1 } { 1 - n _ { 23 } } = 2
$$

Учитывая, что $n _ { 23 } = - \frac { 1 } { n _ { 13 } }$, получим квадратное уравнение относительно $n _ { 13 }$

$$
n _ { 13 } ^ { 2 } + 2 n _ { 13 } - 1 = 0
$$

Решая квадратное уравнение, получаем

$$
n _ { 13 } = - 1 \pm \sqrt { 2 }
$$

Смысл двух корней не только в том, что мы имеем 2 неизвестных показателя политропы, но ещё и в том, что возможно провести 2 разных цикла, меняя направление изобарного процесса.Действительно,если построить качественный график $P ( V )$, станет ясно, что политропы с показателями разного знака могут иметь в точке пересечения давление как выше,так и ниже давления в изобарном процессе.

Теперь найдём значения теплоёмкостей для данных показателей политроп
1)Для $n = - 1 + \sqrt { 2 }$

$$
C _ { 1 } = C _ { V } + \frac { R } { 2 - \sqrt { 2 } } = C _ { P } + \frac { R } { \sqrt { 2 } }
$$

2)Для $n = - 1 - \sqrt { 2 }$

$$
C _ { 2 } = C _ { V } + \frac { R } { 2 + \sqrt { 2 } } = C _ { P } - \frac { R } { \sqrt { 2 } }
$$

В случае, если давление в точке 3 выше, чем в изобарном процессе, $C _ { 13 } = C _ { 2 } , C _ { 32 } = C _ { 1 }$, а в ином случае наоборот.Работу газа в циклах найдём из закона сохранения энергии

В 1 случае

$$
A _ { 1 } = C _ { 2 } \left( T _ { 3 } - T _ { 1 } \right) + C _ { 1 } \left( T _ { 2 } - T _ { 3 } \right) - C _ { P } \left( T _ { 2 } - T _ { 1 } \right) = \frac { R } { \sqrt { 2 } } \cdot \left( \sqrt { T _ { 2 } } - \sqrt { T _ { 1 } } \right) ^ { 2 } = 587,6 \text { Дж }
$$


Во втором случае

$$
A _ { 2 } = C _ { P } \left( T _ { 2 } - T _ { 1 } \right) - C _ { 2 } \left( T _ { 2 } - T _ { 3 } \right) - C _ { 1 } \left( T _ { 3 } - T _ { 1 } \right) = \frac { R } { \sqrt { 2 } } \cdot \left( \sqrt { T _ { 2 } } - \sqrt { T _ { 1 } } \right) ^ { 2 } = 587,6 Д ж
$$

Выражения для работы одинаковы в обоих случаях

А2 ${ } ^ { 1.50 }$ Найдите КПД $\eta$ цикла.

Поскольку работу газа в цикле мы уже знаем,необходимо определить $Q _ { + }$для нахождения КПД цикла.

В первом случае тепло отводится только на изобаре,поэтому из закона сохранения энергии

$$
Q _ { + 1 } = C _ { P } \left( T _ { 2 } - T _ { 1 } \right) + A
$$

Во втором случае тепло подводится только на изобаре, поэтому

$$
Q _ { + 2 } = C _ { P } \left( T _ { 2 } - T _ { 1 } \right)
$$

Выражения для КПД циклов, соответственно

$$
\begin{gathered}
\eta _ { 1 } = \frac { 1 } { \frac { C _ { P } \sqrt { 2 } } { R } \frac { \left( \sqrt { T _ { 2 } } + \sqrt { T _ { 1 } } \right) } { \left( \sqrt { T _ { 2 } } - \sqrt { T _ { 1 } } \right) } + 1 } \\
\eta _ { 2 } = \frac { 1 } { \frac { C _ { P } \sqrt { 2 } } { R } \frac { \left( \sqrt { T _ { 2 } } + \sqrt { T _ { 1 } } \right) } { \left( \sqrt { T _ { 2 } } - \sqrt { T _ { 1 } } \right) } }
\end{gathered}
$$

Учитывая, что $C _ { P } = \frac { \gamma } { \gamma - 1 } R$,ответы приводятся к следующему виду

$$
\begin{gathered}
\eta _ { 1 } = \frac { 1 } { \frac { \gamma \sqrt { 2 } } { \gamma - 1 } \frac { \left( \sqrt { T _ { 2 } } + \sqrt { T _ { 1 } } \right) } { \left( \sqrt { T _ { 2 } } - \sqrt { T _ { 1 } } \right) } + 1 } = \frac { 1 } { 9 \sqrt { 2 } + 1 } \\
\eta _ { 2 } = \frac { 1 } { \frac { \gamma \sqrt { 2 } } { \gamma - 1 } \frac { \left( \sqrt { T _ { 2 } } + \sqrt { T _ { 1 } } \right) } { \left( \sqrt { T _ { 2 } } - \sqrt { T _ { 1 } } \right) } } = \frac { 1 } { 9 \sqrt { 2 } }
\end{gathered}
$$
