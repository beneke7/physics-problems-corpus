С3 ${ } ^ { 1.00 }$ Выразите $\Delta n$ - разницу между коэффициентом преломления $n ( 0 )$ в центре и коэффициентом преломления $n ( R )$ на краю линзы через толщину линзы $l$, фокусное расстояние $F$ и радиус линзы $R$. Считайте, что $\Delta n \ll n$, а внутренний диаметр шприца, из которого выдавливаются цилиндры, равен $D = 8.8$ мм.

Ответ: Оптический путь через центр равен

$$
L _ { 0 } = l n + F ,
$$

а через край линзы

$$
L _ { 1 } = l ( n - \Delta n ) + \sqrt { F ^ { 2 } + R ^ { 2 } } = L _ { 0 } - l \Delta n + F \left( \sqrt { 1 + \frac { R ^ { 2 } } { F ^ { 2 } } } - 1 \right) = L _ { 0 } - l \Delta n + \frac { R ^ { 2 } } { 2 F } .
$$

Из равенства $L _ { 0 } = L _ { 1 }$ выразим финальное соотношение

$$
\Delta n = \frac { R ^ { 2 } } { 2 F l } .
$$
