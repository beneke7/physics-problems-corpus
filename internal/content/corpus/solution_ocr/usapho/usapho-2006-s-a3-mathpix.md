Question 3

a. First. find ?:
$$
\begin{equation*}
\gamma = \frac { C _ { P } } { C _ { V } } = \frac { C _ { 1 } + R } { C _ { 1 } } = \frac { \frac { 3 } { 2 } + 1 } { \frac { 3 } { 2 } } = \frac { 5 } { 3 } \tag{A3-1}
\end{equation*}
$$
Fast processes are adiabatic processes. especially when we are told that no heat exchange occurs! This means that $p V$ is a constant, and then
$$
\begin{equation*}
p _ { 0 } V _ { 0 } ^ { \gamma } = p _ { 1 } V _ { 1 } ^ { \gamma } . \tag{A3-2}
\end{equation*}
$$
But
$$
\begin{equation*}
p V = n R T . \tag{A3-3}
\end{equation*}
$$
so
$$
\begin{equation*}
p V ^ { \gamma } = \frac { n R T } { V } V ^ { \gamma } - n R T V ^ { \gamma - 1 } \tag{A3-4}
\end{equation*}
$$
is a constant. Finally, we can write
$$
\begin{equation*}
T _ { 0 } V _ { 0 } ^ { \top - 1 } = T _ { 1 } V _ { 1 } ^ { \top - 1 } . \tag{A3-5}
\end{equation*}
$$
