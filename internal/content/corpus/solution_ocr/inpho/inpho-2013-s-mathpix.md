6. (a) $g ( r , \theta , \dot { r } , \dot { \theta } ) = \frac { F ( r ) } { m } + r \dot { \theta } ^ { 2 }$
    (b) From null azimuthal component
$$
\begin{aligned}

\frac { d } { d t } \left( r ^ { 2 } \dot { \theta } \right) & = 0 \\

\frac { d } { d t } L & = 0 \\
= \text { constant } &
\end{aligned}
$$
