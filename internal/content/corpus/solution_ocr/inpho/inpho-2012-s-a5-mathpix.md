    (b) Speed of electron $= \left| - \frac { e F _ { 0 } } { m \omega } \sin ( \omega t ) \right|$

    (d) $F _ { 0 } = 1.5 \times 10 ^ { 3 } \mathrm {~V} \cdot \mathrm {~m} ^ { - 1 }$
    (e) Potential energy $= - \frac { e ^ { 2 } } { 4 \pi \epsilon _ { 0 } r } + e F _ { 0 } z$
