## Theory

## III. Plasma Lens

a) Consider cylindrical Gaussian surface of radius $r$ and length $\ell$ about the central axis.
From Gauss's law
$$
\begin{align*}
E 2 \pi r \ell & = \frac { 1 } { \varepsilon _ { 0 } } ( \text { charge inside } )  \tag{0.5points}\\
& = - \frac { 1 } { \varepsilon _ { 0 } } n e \left( \pi r ^ { 2 } \ell \right) \\
E _ { r } & = - \frac { n e r } { 2 \varepsilon _ { 0 } } \tag{0.5point}
\end{align*}
$$
b) From Ampere's law,
$$
\begin{equation*}
B _ { \theta } = - \frac { \mu _ { 0 } n e r v } { 2 } \tag{2points}
\end{equation*}
$$
c) The net Lorentz force is
$$
\begin{equation*}
\vec { F } = \left( \frac { n e ^ { 2 } r } { 2 \varepsilon _ { 0 } } - \frac { \mu _ { 0 } n e ^ { 2 } r v ^ { 2 } } { 2 } \right) \hat { r } = \frac { n e ^ { 2 } r } { 2 \varepsilon _ { 0 } } \left( 1 - \frac { v ^ { 2 } } { c ^ { 2 } } \right) \hat { r } \tag{1point}
\end{equation*}
$$
where $c = \frac { 1 } { \sqrt { \varepsilon _ { 0 } \mu _ { 0 } } }$
d) $\quad F _ { r } \rightarrow 0$ as $v \rightarrow c$, this implies the electric force and magnetic force cancel each other out.
(1 point)
e) The stationary plasma particles have $v = 0$, hence $F _ { r ^ { \prime } } = \pm e E _ { r ^ { \prime } }$
where
$$
E _ { r ^ { \prime } } = - \frac { n e R ^ { 2 } } { 2 \varepsilon _ { o } r ^ { \prime } } + \frac { n _ { o } e r ^ { \prime } } { 2 \varepsilon _ { o } }
$$
for positive ion
$$
F _ { r ^ { \prime } } = - \frac { n e ^ { 2 } R ^ { 2 } } { 2 \varepsilon _ { o } r ^ { \prime } } + \frac { n _ { o } e ^ { 2 } r ^ { \prime } } { 2 \varepsilon _ { o } }
$$
for electron
$$
F _ { r ^ { \prime } } = \frac { n e ^ { 2 } R ^ { 2 } } { 2 \varepsilon _ { o } r ^ { \prime } } - \frac { n _ { o } e ^ { 2 } r ^ { \prime } } { 2 \varepsilon _ { o } }
$$
and there is no cancellation from the magnetic force.
As a result the plasma electrons will be blown out, and the ions are pulled in.
(2 points)
f) The net force on the electron beam in plasma medium is given by,
$$
\begin{equation*}
\vec { F } = \frac { n e ^ { 2 } r } { 2 \varepsilon _ { 0 } } \left( 1 - \frac { v ^ { 2 } } { c ^ { 2 } } \right) \hat { r } - \frac { n _ { 0 } e ^ { 2 } r } { 2 \varepsilon _ { 0 } } \hat { r } \tag{2points}
\end{equation*}
$$
in the limit $v \rightarrow c , \vec { F } \approx - \frac { n _ { 0 } e ^ { 2 } r } { 2 \varepsilon _ { 0 } } \hat { r }$
