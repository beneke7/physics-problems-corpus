II. 1. Consider a shell of width $d r$ which is at the distance $r$ from the centre of the star. Let $\rho$ be the density of star. Gravitational Potential energy of shell is
$$
\begin{align*}
d E _ { G } & = - G \frac { \left( 4 \pi r ^ { 3 } \rho / 3 \right) \left( 4 \pi r ^ { 2 } d r \rho \right) } { r }  \tag{0.5 mark}\\
E _ { G } & = \int _ { 0 } ^ { R } d E _ { G } = - \frac { 3 } { 5 } \frac { G M ^ { 2 } } { R } \tag{0.3 mark}
\end{align*}
$$
It is negative, i.e. gravitational force is radially inward.
