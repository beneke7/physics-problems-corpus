## Solution of Problem No. 1 <br> Measure the mass in the weightless state

1/ Formula for period of oscillation :

$$
\begin{equation*}
T _ { 0 } = \frac { 2 \pi } { \omega _ { 0 } } = 2 \pi \sqrt { \frac { m _ { 0 } } { k } } \tag{1}
\end{equation*}
$$

One can deduce :

$$
\begin{equation*}
m _ { 0 } = \frac { k } { 4 \pi ^ { 2 } } T _ { 0 } ^ { 2 } = 25,21 \mathrm {~kg} \tag{2}
\end{equation*}
$$

2/ When the craft orbits the Earth, oscillating system is the spring with one end attached to the chair of mass $\mathrm { m } _ { 0 }$ and other end attached to he craft with mass M . This system oscillates like an object with mass

$$
\begin{equation*}
\mathrm { m } _ { 0 } ^ { \prime } = \frac { m _ { 0 } M } { m _ { 0 } + M } \tag{3}
\end{equation*}
$$

attached to an end of the spring, other end of the spring is fixed ( $\mathrm { m } _ { 0 }$ ' is the reduced mass of the system craft-chair). The period $\mathrm { T } _ { 0 }$ ' of the system is also given by (1) and (2). We can deduce :

$$
\begin{equation*}
\frac { m _ { 0 } } { m _ { 0 } { } ^ { \prime } } = \left( \frac { T _ { 0 } } { T _ { 0 } { } ^ { \prime } } \right) ^ { 2 } = \left( \frac { 1,28195 } { 1,27395 } \right) ^ { 2 } \tag{4}
\end{equation*}
$$

The mass M of the craft can be calculate from (3) :

$$
\begin{equation*}
\mathrm { M } = \frac { m _ { 0 } } { \frac { m _ { 0 } } { m _ { 0 } { } ^ { \prime } } - 1 } = \frac { 25,21 } { \left( \frac { T _ { 0 } } { T _ { 0 } { } ^ { \prime } } \right) ^ { 2 } - 1 } = \frac { 25,21 } { \left( \frac { 1,28195 } { 1,27395 } \right) ^ { 2 } - 1 } = 2001 \mathrm {~kg} \tag{5}
\end{equation*}
$$

Let m be the mass of astronaut and chair, the coressponding reduce mass is m':

$$
\begin{equation*}
\mathrm { m } ^ { \prime } = \frac { m M } { m + M } \tag{6}
\end{equation*}
$$

the expression of m is then :

$$
\mathrm { m } = \frac { m ^ { \prime } } { 1 - \frac { m ^ { \prime } } { M } }
$$

The reduce mass m' can be calculated from the oscillation period T' by using formula (2) :

$$
\mathrm { m } ^ { \prime } = \frac { 605,6 } { 4 } \cdot \left( \frac { 2,33044 } { 3,1416 } \right) ^ { 2 } = 83,31 \mathrm {~kg}
$$

the true value of the mass m is :

$$
\mathrm { m } = \frac { 83,31 } { 1 - \frac { 83,31 } { 2001 } } = 86,93 \mathrm {~kg}
$$

the true value of the mass of astronaut :

$$
86,93 - 25,21 = 61,72 \mathrm {~kg}
$$
