А1 ${ } ^ { 0.60 }$ С помощью метода наименьших квадратов получите формулы для нахождения коэффициентов $A$ и $B$ для каждого значения температуры $T _ { 0 }$ и для каждого из материалов. Ответ выразите через средние по выборке значения произведений вида $\Delta T ^ { k _ { 1 } } d ^ { k _ { 2 } }$, где $k _ { 1,2 }$ - некоторые числа.

Согласно методу, описанному в условии, составляем систему уравнений:

$$
\left\{ \begin{array} { l }
\frac { \partial S } { \partial A } = 0 \\
\frac { \partial S } { \partial B } = 0
\end{array} , \quad \text { где } \quad S = \sum _ { i } \left( \Delta T _ { i \exp } - \Delta T _ { i \mathrm { th } } \left( d _ { i } , A , B \right) \right) ^ { 2 } = \sum _ { i } \left( \Delta T _ { i } - A d _ { i } + B T _ { 0 } ^ { 1 / 2 } d _ { i } ^ { 3 / 2 } \right) ^ { 2 } \right.
$$

Таким образом, система примет вид:

$$
\left\{ \begin{array} { l }
{ \frac { \partial } { \partial A } \sum _ { i } ( \Delta T _ { i } - A d _ { i } + B T _ { 0 } ^ { 1 / 2 } d _ { i } ^ { 3 / 2 } ) ^ { 2 } = 0 } \\
{ \frac { \partial } { \partial B } \sum _ { i } ( \Delta T _ { i } - A d _ { i } + B T _ { 0 } ^ { 1 / 2 } d _ { i } ^ { 3 / 2 } ) ^ { 2 } = 0 }
\end{array} \Longrightarrow \left\{ \begin{array} { l }
0 = \sum _ { i } \left( \Delta T _ { i } d _ { i } - A d _ { i } ^ { 2 } + B T _ { 0 } ^ { 1 / 2 } d _ { i } ^ { 5 / 2 } \right) \\
0 = \sum _ { i } \left( \Delta T _ { i } d _ { i } ^ { 3 / 2 } - A d _ { i } ^ { 5 / 2 } + B T _ { 0 } ^ { 1 / 2 } d _ { i } ^ { 3 } \right)
\end{array} \right. \right.
$$

Это -- система линейных уравнений относительно коэффициентов $A$ и $B$. Коэффициенты в ней представляют собой необходимые произведения вида $\Delta T ^ { k _ { 1 } } d ^ { k _ { 2 } }$. Через средние значения этих произведений по экспериментальной выборке эта система записывается несколько элегантнее в виде:

$$
\left\{ \begin{array} { l }
0 = \overline { \Delta T d } - A \overline { d ^ { 2 } } + B T _ { 0 } ^ { 1 / 2 } \overline { d ^ { 5 / 2 } } \\
0 = \overline { \Delta T d ^ { 3 / 2 } } - A \overline { d ^ { 5 / 2 } } + B T _ { 0 } ^ { 1 / 2 } \overline { d ^ { 3 } }
\end{array} \right.
$$

Решая эту систему, получим окончательно:

$$
\begin{aligned}
& A = \frac { \overline { \Delta T d ^ { 3 / 2 } } \cdot \overline { d ^ { 5 / 2 } } - \overline { \Delta T d } \cdot \overline { d ^ { 3 } } } { { \overline { d ^ { 5 / 2 } } } ^ { 2 } - \overline { d ^ { 2 } } \cdot \overline { d ^ { 3 } } } \\
& B = \frac { 1 } { \sqrt { T _ { 0 } } } \frac { \overline { \Delta T d ^ { 3 / 2 } } \cdot \overline { d ^ { 2 } } - \overline { \Delta T d } \cdot \overline { d ^ { 5 / 2 } } } { { \overline { d ^ { 5 / 2 } } } ^ { 2 } - \overline { d ^ { 2 } } \cdot \overline { d ^ { 3 } } }
\end{aligned}
$$

Ответ:

$$
\begin{aligned}
& A = \frac { \overline { \Delta T d ^ { 3 / 2 } } \cdot \overline { d ^ { 5 / 2 } } - \overline { \Delta T d } \cdot \overline { d ^ { 3 } } } { { \overline { d ^ { 5 / 2 } } } ^ { 2 } - \overline { d ^ { 2 } } \cdot \overline { d ^ { 3 } } } \\
& B = \frac { 1 } { \sqrt { T _ { 0 } } } \frac { \overline { \Delta T d ^ { 3 / 2 } } \cdot \overline { d ^ { 2 } } - \overline { \Delta T d } \cdot \overline { d ^ { 5 / 2 } } } { { \overline { d ^ { 5 / 2 } } } ^ { 2 } - \overline { d ^ { 2 } } \cdot \overline { d ^ { 3 } } }
\end{aligned}
$$

В1 ${ } ^ { 0.60 }$ С помощью метода наименьших квадратов получите формулу для нахождения коэффициента $A$ для каждого значения температуры $T _ { 0 }$ и для каждого из материалов. Ответ выразите через средние по выборке значения произведений вида $\Delta T ^ { k _ { 1 } } d ^ { k _ { 2 } }$, где $k _ { 1,2 }$ - некоторые числа.

Согласно методу, описанному в условии, составляем систему уравнений:

$$
\left\{ \begin{array} { l }
\frac { \partial S } { \partial A } = 0 \\
\frac { \partial S } { \partial B } = 0
\end{array} , \quad \text { где } \quad S = \sum _ { i } \left( \Delta T _ { i \exp } - \Delta T _ { i \mathrm { th } } \left( d _ { i } , A , B \right) \right) ^ { 2 } = \sum _ { i } \left( \Delta T _ { i } - \frac { A } { d _ { i } } + \frac { B } { d _ { i } ^ { 2 } } \right) ^ { 2 } \right.
$$

Таким образом, система примет вид:


$$
\left\{ \begin{array} { l }
{ \frac { \partial } { \partial A } \sum _ { i } ( \Delta T _ { i } - \frac { A } { d _ { i } } + \frac { B } { d _ { i } ^ { 2 } } ) ^ { 2 } = 0 } \\
{ \frac { \partial } { \partial B } \sum _ { i } ( \Delta T _ { i } - \frac { A } { d _ { i } } + \frac { B } { d _ { i } ^ { 2 } } ) ^ { 2 } = 0 }
\end{array} \Longrightarrow \left\{ \begin{array} { l }
0 = \sum _ { i } \left( \Delta T _ { i } d _ { i } ^ { - 1 } - A d _ { i } ^ { - 2 } + B d _ { i } ^ { - 3 } \right) \\
0 = \sum _ { i } \left( \Delta T _ { i } d _ { i } ^ { - 2 } - A d _ { i } ^ { - 3 } + B d _ { i } ^ { - 4 } \right)
\end{array} \right. \right.
$$

Это -- система линейных уравнений относительно коэффициентов $A$ и $B$. Коэффициенты в ней представляют собой необходимые произведения вида $\Delta T ^ { k _ { 1 } } d ^ { k _ { 2 } }$. Через средние значения этих произведений по экспериментальной выборке эта система записывается несколько элегантнее в виде:

$$
\left\{ \begin{array} { l }
0 = \overline { \Delta T d ^ { - 1 } } - A \overline { d ^ { - 2 } } + \overline { B \overline { d ^ { - 3 } } } \\
0 = \overline { \Delta T d ^ { - 2 } } - A \overline { d ^ { - 3 } } + \overline { B d ^ { - 4 } }
\end{array} \right.
$$

Решая эту систему относительно $A$, получим окончательно:

$$
A = \frac { \overline { \Delta T d ^ { - 2 } } \cdot \overline { d ^ { - 3 } } - \overline { \Delta T d ^ { - 1 } } \cdot \overline { d ^ { - 4 } } } { { \overline { d ^ { - 3 } } } ^ { 2 } - \overline { d ^ { - 2 } } \cdot \overline { d ^ { - 4 } } } .
$$

Ответ:

$$
A = \frac { \overline { \Delta T d ^ { - 2 } } \cdot \overline { d ^ { - 3 } } - \overline { \Delta T d ^ { - 1 } } \cdot \overline { d ^ { - 4 } } } { { \overline { d ^ { - 3 } } } ^ { 2 } - \overline { d ^ { - 2 } } \cdot \overline { d ^ { - 4 } } }
$$

В5 ${ } ^ { 0.60 }$ С помощью метода наименьших квадратов получите формулу для нахождения коэффициента $\Delta T _ { \max }$ для каждого значения температуры $T _ { 0 }$ и для каждого из материалов. Ответ выразите через средние по выборке значения произведений вида $\Delta T ^ { k _ { 1 } } d ^ { k _ { 2 } }$, где $k _ { 1,2 }$ - некоторые числа.

Согласно методу, описанному в условии, составляем систему уравнений:

$$
\left\{ \begin{array} { l }
\frac { \partial S } { \partial \left( \Delta T _ { \max } \right) } = 0 \\
\frac { \partial S } { \partial C } = 0
\end{array} , \quad \text { где } \quad S = \sum _ { i } \left( \Delta T _ { i \exp } - \Delta T _ { i \operatorname { th } } \left( d _ { i } , A , B \right) \right) ^ { 2 } = \sum _ { i } \left( \Delta T _ { i } - \Delta T _ { \max } + C d _ { i } \right) ^ { 2 } \right.
$$

Таким образом, система примет вид:

$$
\left\{ \begin{array} { l }
{ \frac { \partial } { \partial ( \Delta T _ { \operatorname { m a x } } ) } \sum _ { i } ( \Delta T _ { i } - \Delta T _ { \operatorname { m a x } } + C d _ { i } ) ^ { 2 } = 0 } \\
{ \frac { \partial } { \partial C } \sum _ { i } ( \Delta T _ { i } - \Delta T _ { \operatorname { m a x } } + C d _ { i } ) ^ { 2 } = 0 }
\end{array} \Longrightarrow \left\{ \begin{array} { l }
0 = \sum _ { i } \left( \Delta T _ { i } - \Delta T _ { \max } + C d _ { i } \right) \\
0 = \sum _ { i } \left( \Delta T _ { i } d _ { i } - \Delta T _ { \max } d _ { i } + C d _ { i } ^ { 2 } \right)
\end{array} \right. \right.
$$

Это -- система линейных уравнений относительно коэффициентов $A$ и $B$. Коэффициенты в ней представляют собой необходимые произведения вида $\Delta T ^ { k _ { 1 } } d ^ { k _ { 2 } }$. Через средние значения этих произведений по экспериментальной выборке эта система записывается несколько элегантнее в виде:

$$
\left\{ \begin{array} { l }
0 = \overline { \Delta T } - \Delta T _ { \max } + C \bar { d } \\
0 = \overline { \Delta T d } - \Delta T _ { \max } \bar { d } + C \bar { d } ^ { 2 }
\end{array} \right.
$$

Решая эту систему относительно $\Delta T _ { \text {max } }$, получим окончательно:

$$
\Delta T _ { \max } = \frac { \overline { \Delta T } \cdot \overline { d ^ { 2 } } - \bar { d } \cdot \overline { \Delta T d } } { \overline { d ^ { 2 } } - \bar { d } ^ { 2 } }
$$

Ответ:

$$
\Delta T _ { \max } = \frac { \overline { \Delta T } \cdot \overline { d ^ { 2 } } - \bar { d } \cdot \overline { \Delta T d } } { \overline { d ^ { 2 } } - \bar { d } ^ { 2 } }
$$
