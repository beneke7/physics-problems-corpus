Изображение проволоки симметрично относительно $Y$, поэтому проволока лежит в плоскости $x y$. Заметим, что каждая точка проволоки даёт на экране точку (если камера сфокусирована на эту точку) или круг (из подобия конусов).
![](../../../figures/solution-ocr/9c7c9fc71614d60f129576f9.jpg)
Найдём положение окружности и её размеры для точки с координатами $( x , y , 0 )$. Координаты центра окружности из подобия треугольников:

$$
( Y , Z ) = \left( \frac { y l } { x } , 0 \right)
$$

Для диаметра:

$$
\frac { d } { D } = \frac { a - l } { a } = 1 - \frac { l } { a } .
$$

Подставим значение $1 / a$ из формулы тонкой линзы.

$$
\frac { d } { D } = 1 - l \left( \frac { 1 } { f } - \frac { 1 } { x } \right) = 1 - \frac { l ( x - f ) } { f x } .
$$

Найдём зависимость $d$ от $Y$ для $Y > 0$.
![](../../../figures/solution-ocr/8d369d396b9442ee66d305e0.jpg)
По условию $\tan \theta = k$.

$$
d = 2 Y \sin \theta = \frac { 2 k } { \sqrt { 1 + k ^ { 2 } } } \cdot Y = \gamma Y = \gamma \cdot \frac { y l } { x }
$$

где $\gamma = \frac { 2 k } { \sqrt { 1 + k ^ { 2 } } }$.
Подставим это в полученное ранее выражение для $d$.

$$
\frac { d } { D } = \frac { \gamma y l } { D x } = 1 - \frac { l ( x - f ) } { f x }
$$

Выразим $y ( x )$ :

$$
y = \frac { D x } { \gamma l } - \frac { D ( x - f ) } { \gamma f } = \frac { D } { \gamma } - \frac { D x } { \gamma } \left( \frac { 1 } { f } - \frac { 1 } { l } \right) = \frac { D } { \gamma } - \frac { D x ( l - f ) } { \gamma f l } .
$$

Заметим, что так как проволока расположена в области $x > 0$ и изображение точки проволоки в центре экрана является точечным, то камера сфокусирована на одну из точек проволоки, поэтому $l > f$.

Заметим, что мы рассматривали случай $a \geqslant l$, если это не так, то все уравнения останутся верны, но знак у $d$ поменяется. То есть для рассмотрения $a < l$ достаточно в полученных выражениях изменить знак $\gamma$. Таким образом мы получаем, что возможные положения точек определяющих форму изображения:


$$
y = \pm \frac { D ( l - f ) \sqrt { 1 + k ^ { 2 } } } { 2 k l f } \left( \frac { l f } { l - f } - x \right) .
$$

Возможно проволока содержит ещё участки, изображения которых перекрывают изображениями точек на этих прямых, но тогда проволока будет иметь большую длину, что противоречит условию. Поэтому полностью лежит на этих прямых.
![](../../../figures/solution-ocr/398c42ebb048b0506cf68569.jpg)
Заметим, что угловой размер частей прямых $1 ^ { \prime }$ и $2 ^ { \prime }$ меньше $90 ^ { \circ }$ поэтому они могут давать в изображении окружности с ограниченным отрезком положений центров, ещё для фиксированного углового размера длина проволоки на участках 1 и 2 всегда будет меньше, поэтому проволока имеет форму уголка из отрезков 1 и 2:

Ответ:

$$
y = \pm \frac { D ( l - f ) \sqrt { 1 + k ^ { 2 } } } { 2 k l f } \left( \frac { l f } { l - f } - x \right)
$$

при $x \in \left[ 0 , \frac { l f } { l - f } \right]$.

с3 ${ } ^ { 2.00 }$ Определите коэффициенты $\alpha$ и $\beta$ в этом случае. Какая дисторсия наблюдается в такой системе: положительная ( $\alpha$ и $\beta$ одного знака) или отрицательная ( $\alpha$ и $\beta$ разных знаков)?

Заметим, что мы рассматриваем эффекты третьего порядка у параксиальных лучей, поэтому все формулы можно раскладывать до третьего порядка. Найдём связь $R$ и $r$.
![](../../../figures/solution-ocr/b753710474a29549de1bce0b.jpg)
Выразим размеры через углы:

$$
\begin{gathered}
R = l \tan \varphi ; \\
r = ( L - h ) \tan \varphi + h \tan \psi .
\end{gathered}
$$

Связь углов:

$$
\begin{gathered}
n \sin \psi = \sin \varphi . \\
\psi = \arcsin \left( \frac { \sin \varphi } { n } \right) \approx \arcsin \left( \frac { \varphi } { n } - \frac { \varphi ^ { 3 } } { 6 n } \right) \approx \frac { \varphi } { n } - \frac { \varphi ^ { 3 } } { 6 n } + \frac { \varphi ^ { 3 } } { 6 n ^ { 3 } } = \frac { \varphi } { n } - \frac { \varphi ^ { 3 } \left( n ^ { 2 } - 1 \right) } { 6 n ^ { 3 } } \\
\tan \psi \approx \psi + \frac { \psi ^ { 3 } } { 3 } \approx \frac { \varphi } { n } - \frac { \varphi ^ { 3 } \left( n ^ { 2 } - 1 \right) } { 6 n ^ { 3 } } + \frac { \varphi ^ { 3 } } { 3 n ^ { 3 } } = \frac { \varphi } { n } - \frac { \varphi ^ { 3 } \left( n ^ { 2 } - 3 \right) } { 6 n ^ { 3 } } \\
\varphi = \arctan \left( \frac { R } { l } \right) \approx \frac { R } { l } - \frac { R ^ { 3 } } { 3 l ^ { 3 } }
\end{gathered}
$$


$$
\begin{gathered}
\tan \psi \approx \frac { R } { n l } - \frac { R ^ { 3 } } { 3 l ^ { 3 } n } - \frac { R ^ { 3 } \left( n ^ { 2 } - 3 \right) } { 6 l ^ { 3 } n ^ { 3 } } = \frac { R } { n l } - \frac { R ^ { 3 } \left( n ^ { 2 } - 1 \right) } { 2 l ^ { 3 } n ^ { 3 } } \\
r = \frac { L - h } { l } R + \frac { h } { n l } R - \frac { h \left( n ^ { 2 } - 1 \right) } { 2 l ^ { 3 } n ^ { 3 } } R ^ { 3 } = \frac { n L - ( n - 1 ) h } { n l } R - \frac { h \left( n ^ { 2 } - 1 \right) } { 2 l ^ { 3 } n ^ { 3 } } R ^ { 3 }
\end{gathered}
$$

Осталось выразить $R$. Введём обозначения:

$$
\begin{gathered}
A = \frac { n L - ( n - 1 ) h } { n l } ; \quad B = \frac { h \left( n ^ { 2 } - 1 \right) } { 2 l ^ { 3 } n ^ { 3 } } . \\
r = A R - B R ^ { 3 } \\
r \approx A \left( \alpha r + \beta r ^ { 3 } \right) - B \alpha ^ { 3 } r ^ { 3 } = A \alpha r + \left( A \beta - B \alpha ^ { 3 } \right) r ^ { 3 }
\end{gathered}
$$

Приравняем коэффициенты при одинаковых степенях и выразим искомые коэффициенты:

$$
\begin{gathered}
\left\{ \begin{array} { l }
A \alpha = 1 ; \\
A \beta - B \alpha ^ { 3 } = 0 .
\end{array} \right. \\
\alpha = \frac { 1 } { A } = \frac { n l } { n L - ( n - 1 ) h } \\
\beta = \frac { B } { A ^ { 4 } } = \frac { h n l \left( n ^ { 2 } - 1 \right) } { 2 ( n L - ( n - 1 ) h ) ^ { 4 } }
\end{gathered}
$$

Ответ: Наблюдается положительная дисторсия.

$$
\alpha = \frac { n l } { n L - ( n - 1 ) h } \quad \beta = \frac { h n l \left( n ^ { 2 } - 1 \right) } { 2 ( n L - ( n - 1 ) h ) ^ { 4 } }
$$
