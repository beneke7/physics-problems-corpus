А1 ${ } ^ { 0.20 }$ Измерьте фокусные расстояния $f$ и $F$ с помощью получения изображения $A ^ { \prime }$ на экране. Для измерения используйте $H \approx 1.20$ м. В листе ответов крестиком укажите соответствие между цветом линзы и названиями $L _ { f }$ и $L _ { F }$.

Воспользуемся формулой тонкой линзы

$$
\frac { 1 } { a } + \frac { 1 } { H - a } = \frac { 1 } { f }
$$

Для каждой линзы сделаем по два измерения.
Белая линза:
Ближняя фокусировка:

$$
H = 124.2 \mathrm {~cm} , \quad a = 7.3 \mathrm {~cm} \quad \Rightarrow \quad f = 6.9 \mathrm {~cm}
$$

Дальняя фокусировка:

$$
H = 124.2 \mathrm {~cm} , \quad a = 116.5 \mathrm {~cm} \quad \Rightarrow \quad f = 7.2 \mathrm {~cm}
$$

Синяя линза:
Ближняя фокусировка:

$$
H = 124.5 \mathrm {~cm} , \quad a = 18.0 \mathrm {~cm} \quad \Rightarrow \quad F = 15.4 \mathrm {~cm}

Дальняя фокусировка:

$$
H = 124.2 \mathrm {~cm} , \quad a = 103.2 \mathrm {~cm} \quad \Rightarrow \quad F = 17.4 \mathrm {~cm}

Из формулы тонкой линзы

$$
\frac { 1 } { b } + \frac { 1 } { a } = \frac { 1 } { F } \quad \Rightarrow \quad b = \frac { F a } { a - F }
$$

а размер $w ^ { \prime }$ изображения $A ^ { \prime }$ равен $W _ { A } \frac { b } { a }$ и не зависит от сфокусированности на экране.
При $a > a _ { 0 }$ граница изображения на экране определяется лучем, проходящим через противоположный край линзы. Из геометрии:

$$
\frac { w - w ^ { \prime } } { H - a - b } = \frac { D + w ^ { \prime } } { b }
$$

Путем преобразований получим:

$$
w = W _ { A } \frac { H - a } { a } + D \frac { a ^ { 2 } - a H + F H } { a F }

\frac { w - w ^ { \prime } } { a + b - H } = \frac { D - w ^ { \prime } } { b }
$$

Путем преобразований получим:

$$
w = W _ { A } \frac { H - a } { a } - D \frac { a ^ { 2 } - a H + F H } { a F }

E2 ${ } ^ { 1.74 }$ Получите теоретическую формулу для зависимости $h$ от $a$. Постройте линеаризованный график и покажите, что теоретическая формула справедлива.
![](../../../figures/solution-ocr/5f60d3e43cad3ddf3d1f53c5.jpg)
Формулы тонкой линзы:

$$
\begin{gathered}
\frac { 1 } { a } + \frac { 1 } { b } = \frac { 1 } { F } \Rightarrow b = \frac { a F } { a - F } \\
\frac { 1 } { x } + \frac { 1 } { L _ { 1 } - x } = \frac { 1 } { f } , \quad L _ { 1 } = H - a - b
\end{gathered}
$$

Получим уравнение на $x$ из второй формулы тонкой линзы:

$$
x ^ { 2 } - x L _ { 1 } - f L _ { 1 } = 0 , \quad \mathcal { D } = L _ { 1 } ^ { 2 } - 4 f L _ { 1 } , \quad x _ { 1,2 } = L _ { 1 } \frac { 1 \pm \sqrt { 1 - \frac { 4 f } { L _ { 1 } } } } { 2 } .
$$

При меньшем $x$ изображение больше, поэтому выбираем корень с минусом.
Теперь выразим высоту $h$ изображения $A ^ { \prime \prime }$, пусть высота $A ^ { \prime } - h ^ { \prime }$. Из подобных треугольников:

$$
\frac { H _ { A } } { a } = \frac { h ^ { \prime } } { b } , \quad \frac { h ^ { \prime } } { x } = \frac { h } { L _ { 1 } - x } .
$$


В итоге

$$
h = \frac { L _ { 1 } - x } { x } \frac { b } { a } H _ { A } = \frac { 1 + \sqrt { 1 - \frac { 4 f } { L _ { 1 } } } } { 1 - \sqrt { 1 - \frac { 4 f } { L _ { 1 } } } } \frac { F } { a - F } H _ { A } ,
$$

где $L _ { 1 } = H - a - \frac { a F } { a - F }$.
Таким образом линеаризация $h$ от $X _ { 3 }$, где

$$
X _ { 3 } = \frac { 1 + \sqrt { 1 - \frac { 4 f } { H - a - \frac { a F } { a - F } } } } { 1 - \sqrt { 1 - \frac { 4 f } { H - a - \frac { a F } { a - F } } } } \frac { F } { a - F } .
$$

![](../../../figures/solution-ocr/03ebd452c544954279602886.jpg)

Ответ: Коэффициент наклона графика $k = 0.35$ см, что полностью соответствует $H _ { A }$ полученному в других пунктах.
