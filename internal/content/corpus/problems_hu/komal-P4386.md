P. 4386. Bizonyos tömegű ideális gáz az ábrán látható körfolyamatot végzi. A gáz hőmérséklete az A  állapotban T $_{ A }$=200 K, a  C  állapotban T $_{ C }$=1800 K.

 a ) Hányszor nagyobb a gáz nyomása a  B  állapotban, mint a  D  állapotban?
 b ) Mekkora hőmérséklet tartozik a kör középpontján átmenő izotermához?
 c ) Igazoljuk számítással, hogy a B és D  állapotokhoz azonos hőmérséklet tartozik!
