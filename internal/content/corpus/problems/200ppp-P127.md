When a particular line spectrum is examined using a diffraction grating of 300 lines $\mathrm{mm}^{-1}$ with the light at normal incidence, it is found that a line at $24.46^{\circ}$ contains both red ( $640-750 \mathrm{~nm}$ ) and blue/violet ( $360- 490 \mathrm{~nm})$ components. Are there any other angles at which the same thing would be observed?
