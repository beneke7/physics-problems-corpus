Q7

A radioactive source contains a mixture of two unrelated radioactive substances, A and B , with decay constants, $\lambda_{\mathrm{A}}$ and $\lambda_{\mathrm{B}} ; \mathrm{A}$ has the larger decay constant. A counter which is $60 \%$ efficient at detecting all the decays of nuclei A, but only $11 \%$ efficient for those of substance B. At time $\mathrm{t}=0, \mathrm{~A}$ and B produce $N_{A}$ and $N_{B}$ counts per minute, respectively. The results of the experimental measurements for the total counts are given in Table 7.1.

| $t$ Time / days | $N$ Counts / min. |
| :---: | :---: |
| 0.5 | 7000 |
| 2.0 | 620 |
| 5.0 | 142 |
| 9.0 | 76 |
| 15.0 | 28 |

Table 7.1

(a) (i) Write down the equation for $N$, the number of counts per minute detected by the counter.
(ii) Deduce the behaviour of $N$ for large $t$.
(iii) Using (ii) plot a suitable graph in order to determine $N_{\mathrm{B}}$ and $\lambda_{\mathrm{B}}$.
(iv) What is the initial number of B atoms present?
(b)
(i) Extrapolate the graph to obtain a value of $N$ at time $t=0$ and hence determine $N_{\mathrm{A}}$.
(ii) Using the first experimental result in Table 7.1, determine $\lambda_{\mathrm{A}}$.
