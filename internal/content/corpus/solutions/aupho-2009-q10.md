An equation is dimensionally correct if the quantities on both sides have the same
physical dimensions, e.g. length (L), mass (M), time (T), and combinations. For
example, distance, d, is a length and speed, v, is a length per unit time, so d = vt is
dimensionally correct if t represents a time. Equations cannot be physically correct unless
they are dimensionally correct.
